# Stability analysis

The [TimestepperTheory package](theory.md) implements the manuscript's amplification factors, averaging filters, and coupled modal stability analysis. Its [Literate example](generated/time_discretization.md) shows the computations and figures for Sections 2–4.

See the [example guide](theory_example.md) for execution commands and the [theory API](theory_api.md) for the matrix construction and perturbation diagnostics.
